lauschbox

DNS-Logging für deine FRITZ!Box — mit Gerätefilter, Sperrliste und Telegram-Push bei Treffern. Direkt im Terminal.

curl -fsSL … | sh

macOS & Linux · Script nach ~/.local/bin · Konfiguration & blocklist.txt nach ~/.config/lauschbox

Screenshots Zum Repo ↗

Features

🔌

Fritzbox-Zugang

IP, Benutzername, Passwort — sicher in .fritzbox.env (chmod 600) gespeichert.

📱

Gerätefilter

Verbundene Geräte live von der Box auflisten. Einzel- oder Mehrfachauswahl — clientseitig per MAC, deckt IPv4 & IPv6 ab.

📡

Live-DNS-Logging

Zeitstempel, Gerätename, IP und Domain in Echtzeit — via Paketaufzeichnung & tshark.

🚫

Sperrliste

blocklist.txt mit Suffix-Matching. Treffer werden immer rot markiert — gefiltert nur auf Wunsch.

✈️

Telegram-Push

Jeder Sperrlisten-Treffer löst sofort eine Nachricht aus — asynchron, ohne die Anzeige zu bremsen.

🎨

Catppuccin Macchiato

Durchgehendes Farbschema, fixiertes Banner, klare Statusleiste — auch auf kleinen Terminals.

Setup

1 · FRITZ!Box vorbereiten

  • Benutzer anlegen: System → FRITZ!Box-Benutzer → Benutzer hinzufügen (Recht „FRITZ!Box Einstellungen“)
  • TR-064 erlauben: Heimnetz → Netzwerk → Netzwerkeinstellungen → „Zugriff für Anwendungen zulassen“
  • Zugang in der App unter 1 · Verbindung Fritzbox eintragen

2 · Werkzeuge installieren

ToolmacOSDebian/Ubuntu
figletbrew install figletapt-get install figlet
curlbrew install curlapt-get install curl
tsharkbrew install wiresharkapt-get install tshark
python3brew install pythonapt-get install python3

3 · Installieren & starten

curl -fsSL … | sh

oder klassisch:

git clone https://github.com/forbidden-fruits/lauschbox
cd lauschbox
./lauschbox

Der Installer legt ~/.config/lauschbox an und lädt blocklist.txt und lauschbox.env (Puffer-Limits LOG_MAX_LINES/BLOCKLIST_MAX_LINES, je 1000) dorthin. lauschbox sucht Konfigdateien (.fritzbox.env, .telegram.env, .devices.env, lauschbox.env) und die Sperrliste zuerst im aktuellen Verzeichnis, danach in ~/.config/lauschbox. Fehlt lauschbox.env an beiden Orten, wird sie mit Defaults im aktuellen Verzeichnis angelegt.

4 · Telegram (optional)

  • Bot bei @BotFather anlegen (/newbot) → Token
  • Dem Bot einmal /start schicken
  • Chat-ID via @userinfobot oder getUpdates ermitteln
  • In der App unter 2 · Verbindung Telegram eintragen

Nutzung

Tasten im Logging

eGerätefilter ändern
sSperrliste an/aus (an = nur Treffer)
tTelegram an/aus (nur mit Sperrliste)
xzurück zum Hauptmenü
↑/↓zeilenweise scrollen
PgUp/PgDnseitenweise scrollen
Home/EndeAnfang / zurück zum Live-Ende
Mausradscrollen

Beim Hochscrollen pinnt die Ansicht — neue Einträge laufen im Hintergrund weiter (Ringpuffer, einstellbar via LOG_MAX_LINES in lauschbox.env) und werden in der Statuszeile gezählt. Ende kehrt zur Live-Ansicht zurück. Banner und Statusleiste bleiben statisch.

blocklist.txt

# eine Domain pro Zeile
example.com
tracking.example.org

Suffix-Matching: ein Eintrag matcht auch alle Subdomains. # am Zeilenanfang = Kommentar. Gesucht wird zuerst im aktuellen Verzeichnis, dann unter ~/.config/lauschbox/blocklist.txt. Die Übersicht (Menü 5) ist scrollbar; eingelesen werden max. BLOCKLIST_MAX_LINES Zeilen (s. lauschbox.env).

Bekannte Grenzen

Angezeigt wird nur, was bei der Fritzbox ankommt: DNS-Cache, DoH/DoT, iCloud Private Relay oder VPN am Gerät machen Queries unsichtbar.
